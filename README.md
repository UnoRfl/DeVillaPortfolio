# Carl Angelo D. De Villa — Portfolio

A static, image-led portfolio concept for Carl, styled with the charcoal, warm-metal accents, soft clay surfaces, and page transitions from Uno's portfolio.

## Live site

https://unorfl.github.io/DeVillaPortfolio/home/

The site is served with GitHub Pages from the `main` branch and repository root. It has no build step or dependencies.

## Pages

- `/home/` — image gallery with category filters and click-to-enlarge viewer
- `/about/` — introduction, portrait, and game-development goal
- `/contact/` — email, phone, and course

The site root forwards visitors to `/home/`. All navigation uses clean paths without `.html` endings.

The gallery images are by other creators. Each image has an on-page credit and a link to its Unsplash source page. The images are sample curation, not Carl's original work. Carl's portrait was provided for this portfolio and is used for his profile and link preview.
