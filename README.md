# Carl Angelo D. De Villa — Visual Gallery

A static, image-led portfolio concept for Carl, styled with the charcoal, warm-metal accents, soft clay surfaces, and page transitions from Uno's portfolio.

## Preview

Open `index.html` in a browser. The site has no build step or dependencies.

## Pages

- `index.html` — image gallery with category filters and click-to-enlarge viewer
- `about.html` — introduction and game-development goal
- `contact.html` — email, phone, and course

The gallery images are by other creators. Each image has an on-page credit and a link to its Unsplash source page. The images are sample curation, not Carl's original work.

## Publish with GitHub Pages

In the repository settings, enable GitHub Pages from the `main` branch and repository root.
